## About Me

I am a Geo AI Engineer based in Hyderabad, India, with hands-on experience in training and deploying deep learning and machine learning models for geospatial applications. I specialize in object detection, semantic segmentation, and instance segmentation on high-resolution aerial and satellite imagery, and in automating complex GIS workflows using Python.

I hold an M.Sc in Geoinformatics from Bharati Vidyapeeth Institute, Pune (CGPA 8.93), and was selected as a Chanakya Postgraduate Fellow at IIT Tirupati Navavishkar I-Hub Foundation.

- Currently working at WhereSoft Technologies on deep learning-based GeoAI solutions
- Experience deploying object detection models on FastAPI and Django backends
- Building LLM-based AI agents for GIS tasks using LangChain, Mistral, and Gemini APIs
- Winner of the Geo Innovation Challenge for Sustainable Nation 2024 (DST, Govt. of India)
- Recipient of the Outstanding Intern Award from the Director of ISRO's National Remote Sensing Centre
- Fluent in English, Hindi, and Bengali

## Experience

**Geo AI Engineer — WhereSoft Technologies Pvt Ltd** (July 2025 – Present)

- Training and deploying deep learning models in the Esri deep learning Python ecosystem and standard Python environments
- Object detection projects including palm tree detection and agricultural pit detection using CNN-based architectures
- Semantic and instance segmentation projects including building footprint extraction and pond boundary segmentation using Fast R-CNN and Vision Transformer architectures
- Deploying custom-trained and pre-trained models on a FastAPI backend with API endpoint development and Postman testing
- Building LLM-based AI agents using Mistral and Gemini APIs for GIS tasks via LangChain and vector databases
- Automating GIS workflows with ArcPy, Rasterio, GDAL, and geoai-py

**Junior Data Analyst — Garudalytics Pvt Ltd** (March 2024 – June 2025)

- Analyzed geospatial raster and vector datasets using Python, ArcGIS Pro, and QGIS
- Deployed custom object detection models in an offline environment on a Django backend for a defense project
- Contributed to GeoAI tools for Garudalytics' flagship GSM product: heatwave prediction, flood depth and impact analysis, building footprint extraction, wildfire impact analysis, and crop yield prediction
- Developed a custom georeferencing and mosaicking tool using PyQt5
- Developed Disha, a QGIS plugin for least-cost route calculation for strategic use cases

**Chanakya Postgraduate Fellow — IIT Tirupati Navavishkar I-Hub Foundation** (June 2024 – Aug 2025)

- Project: Object Detection for Coastal Surveillance System using Deep Learning
- Developed zone-based detection enabling custom surveillance regions on live video feeds with real-time alerting
- Built an automated Telegram bot alert system for object detection notifications

**Geospatial Associate — Social Responsibility Asia (SR Asia)** (Oct 2023 – Dec 2023)

- Collected socio-demographic data through field surveys using Survey123
- Analyzed datasets and prepared maps in ArcGIS Pro for Re-Settlement Action Planning (RAP) for coal-mine affected villages
